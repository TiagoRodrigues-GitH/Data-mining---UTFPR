# Data Mining – UTFPR Master Class 2026



Data Mining is the process of discovering meaningful patterns, trends, and insights from large datasets by combining techniques from machine learning, statistics, and database systems. It turns raw data into actionable knowledge through tasks like classification, clustering, regression, and association analysis.

This repository contains the practical activities, exercises, and implementations developed during the **Data Mining Master Class** at the Federal University of Technology – Paraná (UTFPR) in 2026.
